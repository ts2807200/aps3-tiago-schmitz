ADR 0001 — Uso de NodeJS no Back End
Status Aprovada

Necessidade de alterar a necessidade da linguagem de servidor para uma linguagem assicrona, mais rápida e eficiente e condizente com o mercado atual.

Foi decidido o uso do Node JS por ser uma linguagem rápida, assicrona que por padrão já possui bibliotecas para conexão com banco de dados, filas e workers.

Com isso obtemos uma linguagem de servidor mais rápida, estável, moderna e eficiente principalmente para melhoria continua, o maior desafio seria a alteração de sistemas legado
